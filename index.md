The **Bear & Moose GeoIP Project** provides a GeoIP service. Clients send the server an IP address, and the server responds with location information. Messaging is over ZMQ. The service runs as a Linux systemd service. It retrieve the GeoIP data from a public provider on a scheduled basis.
